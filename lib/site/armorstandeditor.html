ArmorStandEditor

Pose armor stands and change their settings in survival without typing commands.

What it does

Armor stands are great for displaying armor, items, and statues, but posing them normally needs complicated commands. ArmorStandEditor gives you an editing tool and a simple menu instead.

Getting started

  1. Hold the editing tool in your main hand. By default it is a flint.
  2. Left- or right-click away from an armor stand to open the menu.
  3. Pick an option from the menu (for example, which body part and which direction to rotate).
  4. Left- or right-click the armor stand with the tool to apply your choice.

Handy tips

  • Shift + scroll wheel quickly changes the axis you're rotating on.
  • Coarse adjustment moves a part in big steps; switch to fine adjustment to tweak the last bit.
  • You can copy an armor stand's settings and paste them onto another one. The plugin switches to paste mode automatically after copying.
  • Pressing F with the tool in hand targets an armor stand.
  • You can name an armor stand with a normal name tag.
  • On claimed land, the plugin generally respects protection plugins, so you can only edit stands you're allowed to.
Bedrock players: some controls (scroll wheel, the F key) work differently on phones, tablets and consoles. If a shortcut doesn't work for you, use the menu options instead, or consult the wikis (or me, if I'm feeling nice).
