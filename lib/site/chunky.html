Chunky

Chunky loads chunks ahead of time so exploring stays smooth.

What it does

Minecraft normally creates new terrain the moment someone walks or flies into it, which can cause lag. Chunky lets you pre-generate a large area in advance so the world is already there when you arrive.

What this means for players

  • Exploring and flying (especially with an elytra) should be smoother.
  • You may notice the server is a little slower if a pre-generation job is running. Shouldn't happen often, but it'll be quick if it happens.
  • Pre-generating doesn't change your builds or items; it only creates terrain that hasn't been visited.

Chunky is mostly an admin tool, so there's nothing you need to do as a player.
