Geyser

Geyser is the translator that lets Bedrock Edition players join a Java Edition server.

What it does

Minecraft comes in two editions that normally can't play together. Java Edition runs on PC, Mac, and Linux. Bedrock Edition runs on phones, tablets, Windows (the Microsoft Store version), Xbox, PlayStation, and Switch. The server is a Java server, and Geyser translates between the two so everyone can play on the same world on their preferred version.

Geyser works together with Floodgate, which handles signing in.

Joining from Bedrock

  1. Open Minecraft and choose Play, then the Servers tab.
  2. Scroll to the bottom and choose Add Server.
  3. Enter any name, the server address, and the port.
  4. Save, select the server, and press Join Server. You sign in with your normal Microsoft/Xbox account.
On Xbox, PlayStation or Switch? Consoles have no Add Server button because console developers are lame.
See console workarounds.

What feels different on Bedrock

  • Some controls and menus differ between editions. A few Java-only features may look or behave slightly differently.
  • Your name may show a prefix (usually a dot) so it never clashes with a Java player's name. See Floodgate.
  • If you see a "version mismatch" message, Bedrock updated before the server did. I'll have to update Geyser to fix it, so send me a ping on Discord.
