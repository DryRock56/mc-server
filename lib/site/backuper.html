Backuper

Backuper backs up the world in the background every so often so mistakes and crashes don't cost you your builds.

What it does

Backuper makes automatic backups of the server on a schedule. Old backups are cleaned up automatically so storage doesn't fill up.

What this means for players

  • If something goes catastrophically wrong (a crash, an unwelcome grief, etc.), I can usually restore the world from a recent backup.
  • Backups can cause a brief message in chat or a short slowdown while they run.
  • A restore rolls the world back to the backup time, so anything built after that point may be lost. Let me know if you notice a problem.

You don't need to use any commands as a player.
