Floodgate

Floodgate lets Bedrock players sign in with their Microsoft/Xbox account without needing Java Edition.

What it does

The server normally checks that players own Java Edition. Floodgate works alongside Geyser so Bedrock players are verified through their Xbox/Microsoft account instead. You don't need to do anything special; just join as described on the Geyser page.

Why does my name start with a dot?

Bedrock and Java players can have the same name. Floodgate adds a prefix (a dot by default) to Bedrock names to avoid clashes, so Steve on Bedrock shows up as .Steve.

Tip for commands: if a command needs your name or a friend's name, include the dot. Names with spaces appear with underscores instead.

Linking your Java and Bedrock accounts

If you play on both editions, Floodgate supports account linking (if enabled). This let you log in as the same player with all your items and such on either edition. I have no idea if this is enabled, but if you wanna do it let me know and I'll figure it out.
