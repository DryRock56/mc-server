Joining other servers from Bedrock

How Bedrock players can connect to third-party servers, depending on the device you play on.

Our own server works the same way as any other: see the Geyser page for steps.

First: which kind of server is it?

A Bedrock player can only join a server that accepts Bedrock connections. That means either a native Bedrock server, or a Java server running Geyser (like this one). A plain Java server without Geyser can't be joined from Bedrock. Note that the address and port will be different for Java and Bedrock Editions.

Phones, Tablets, and PC

This is the easiest method, and works on Android, iOS/iPadOS and Windows Bedrock (and Linux if you have the sauce).

  1. Open Minecraft, choose Play, then the Servers tab.
  2. Scroll down and choose Add Server.
  3. Enter a name, the server's Bedrock address, and the port.
  4. Save, then select the server and join. You only have to add it once.

Consoles: Xbox, PlayStation and Switch

Consoles have no Add Server button, so you need a workaround. These are third-party tools, not made by Mojang, and can stop working after game updates.

Option A: Join through a friend

  1. Have a friend on a phone or PC join the server using Add Server (I can help with this if I'm available).
  2. Make sure you and that friend are on each other's Minecraft friends list.
  3. On your console, open Play, then the Friends tab, and join their session.

Option B: BedrockConnect

BedrockConnect gives consoles a server list they can type addresses into.

  • DNS method: change your console's DNS settings to the BedrockConnect address listed on the project page, then open a featured server in the Servers tab. A BedrockConnect menu appears where you can add any server.
  • Add Friend method: the project also describes a way to reach BedrockConnect by adding a special friend account, which avoids changing DNS.
Be careful with DNS: changing DNS sends part of your console's network traffic through someone else's server. Only use addresses published by the official BedrockConnect project, and change them back when you're done. Don't enter your Microsoft password anywhere other than the normal sign-in screen.

Option C: Phone broadcast apps

Some phone apps can advertise a server to your console so it appears in the Friends tab. The phone must stay on the same network and open while you join. These apps change frequently, so check recent reviews before installing.

Troubleshooting

ProblemWhat to try
Version mismatchBedrock updates itself, and the server may be behind or ahead. Check the server's announcements.
Can't connectDouble-check the address, port, and that you chose a Bedrock address (not a Java one).
Works on phone, not consoleThe server is fine; the console workaround is the problem. Try a different option above.
Signed in as the wrong accountMake sure you're signed into the Microsoft/Xbox account you want to play with.
