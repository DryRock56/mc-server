ImageFrame

Turn a picture from the internet into a map you can hang on a wall.

What it does

ImageFrame converts an image or GIF into Minecraft maps. You can then place those maps in item frames to build a poster or mural. Images can be sized across several maps.

Permissions: creating images/animations is likely limited by default. If a command says you don't have permission, ping me and I'll fix it. I plan on setting up the defaults so everyone can do it, but as of writing that is not done.

Quick start

  1. Find a direct link to an image (a URL that ends in .png or .jpg works best).
  2. Place item frames on a wall in the size of picture you want, for example 3 wide by 2 tall.
  3. Get as many empty maps as you need to fill the desired grid.
  4. Select the frames: /imageframe select and follow the prompt.
  5. Create the image: /imageframe create <name> <url> <width> <height>. Use the same width and height as your frame grid, e.g. /imageframe create sunset https://example.com/sunset.png 3 2

You can also add selection to put the image directly into the frames you selected, or combined to get one item that places the whole image in one click.

Performance: I have not tested the performance implications of this plugin, but it's likely that too many can cause lag (especially GIFs). Please make images in moderation.

Useful commands

CommandWhat it does
/imageframe selectSelect item frames to put images on
/imageframe create <name> <url> <width> <height>Create a new image map
/imageframe listList the image maps you've made
/imageframe get <name>Get a copy of an image map you made
/imageframe infoShow details about the map in your hand
/imageframe refreshReload an image from its original link
/imageframe rename <name> <new_name>Rename an image
/imageframe delete <name>Delete an image map you made

Tip: /imageframe can also be typed as /if.

Good to know

  • Keep image content appropriate; the server rules apply to pictures too.
  • Maps display at a limited resolution and color range, so simple, high-contrast images look best.
  • Bedrock players may experience some visual glitches/artifacts with GIFs.
  • Chat messages have a character limit, so some long image links may not work. Use TinyURL to shorten links if necessary.
Please don't make images that are inappropriate or offensive, and DEFINITELY don't make anything sexually explicit. Keep your gooning material on a different tab, you weirdo.
